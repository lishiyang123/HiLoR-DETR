# Algorithm reference for the RT-DETR adaptation

This reference snapshot documents the DEIM-side definitions used when adapting
auxiliary geometry, classification-role adjustment, competition mapping and
candidate-value estimation to RT-DETR. Upstream copyright and license notices
remain applicable.

Use `../../source/RT-DETR_HiLoR/rtdetr_pytorch/` and the commands in
`../../README.md` for executable second-host reproduction. The shared main-host
implementation is `../../../main_host/source/FINAL_CODE/`.

Reference algorithm files, difficulty statistics and the fixed fitting settings
are retained for attribution and semantic comparison. The optional release-wide
inventory describes the distributed files. Recorded experiment identities and
the active fitting-tool checks remain unchanged.
