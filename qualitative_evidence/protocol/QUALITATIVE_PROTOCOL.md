# CDW1630 qualitative comparison and failure-case protocol

This protocol is frozen before exporting or inspecting the paired Test predictions.
It uses the formal seed-0 B0 and Ours checkpoints, the final checkpoint-specific
QCCR/UMR assets, and the official CDW1630 Test split from the main reproduction
package.

The representative set is prediction-blind. Six images are selected using only
ground-truth annotations: three fixed empirical density-rank targets crossed with
two fixed ground-truth box-overlap-rank targets. Each target receives the nearest
unused image, with integer image ID as the deterministic tie break.

Improvement and failure sets are explicitly post-hoc reporting sets. Predictions
are filtered at the same display-only score threshold for both methods and matched
to ground truth by class-aware greedy matching. The primary ranking is the paired
change in image-level F1 at IoU 0.75, followed by the change at IoU 0.50 and image
ID. The full candidate ranking is retained; the displayed subset is never used to
select a model, checkpoint, calibration parameter, or claim a dataset-level metric.

Boxes, labels, scores, sample membership, and ranking values are generated by the
pipeline and must not be edited in graphics software. Cosmetic changes such as
font substitution or panel spacing are permitted only after the generated source
data and SHA bindings remain attached.
